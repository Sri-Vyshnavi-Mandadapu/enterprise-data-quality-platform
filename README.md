# Smart Data Cleaning & Reporting Automation

An intelligent data preprocessing system that automates cleaning, validation, quality assessment, and reporting for CSV datasets.

## Features

- Missing Value Detection
- Duplicate Removal
- Outlier Detection
- Data Quality Scoring
- PDF Report Generation
- Excel Export
- Interactive Dashboard

## Technologies

Python, Pandas, NumPy, Streamlit, Plotly

## Run

pip install -r requirements.txt

streamlit run app.py
